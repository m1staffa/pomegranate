# Pomegranate

Pomegranate Windows üçün faylları çevirmək, şəkilləri kəsmək və PDF-ləri birləşdirib sıxışdırmaq üçün masaüstü tətbiqidir.

**[Windows x64 üçün yüklə](https://github.com/m1staffa/pomegranate/releases/latest/download/Pomegranate-Windows-x64.zip)** · **[Təlimat və brauzer demosu](https://m1staffa.github.io/pomegranate/)**

ZIP-i bir qovluğa tam çıxar və `Pomegranate.exe` faylını aç. Media və sənəd çevirmələri üçün proqramdakı **Alətləri hazırla** bölməsinə bax.

Dairəvi sürüklə-burax iş üsulu [Tangerine for Mac](https://tangerineformac.com/)-dan ilhamlanıb. [Lisenziyalar və müəllif bildirişləri](docs/licenses.html) saytda və Windows paketində yer alır.
